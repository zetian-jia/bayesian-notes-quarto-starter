考虑只有”成功”和”失败”的独立试验，如果每次成功概率为 \(\theta\)，则称这些试验为有参数 \(\theta\) 的 Bernoulli 试验，而试验结果是”成功”还是”失败”的分布为 \(\text{Bernoulli}(\theta)\) 分布。如果在 \(n\) 次 Bernoulli 试验中，有 \(s\) 次成功（那么一定有 \(f=n-s\) 次失败），则成功的次数称为服从有参数 \((n,\theta)\) 的二项分布。Bernoulli 分布是二项分布在 \(n=1\) 时的特例。人们一般希望用试验中成功个数或者比例来对参数 \(\theta\) 做推断。形式上，记观测值 \(\boldsymbol{x}=(x_1,x_2,\ldots,x_n)\) 为参数 \(\theta\) 的 Bernoulli 试验的结果，对应于”成功”或”失败”，每个 \(x_i\) 取值为 1 或 0。

3.1 4.1 采用简单共轭先验分布

取 \(\theta\) 的先验分布 \(p(\theta)\) 为共轭先验分布 \(\text{Beta}(\alpha,\beta)\)，则 \(s=x_1+x_2+\cdots+x_n\) 为一个充分统计量。后验分布

$$ p() () = s(1-){n-s}{}(1-){}

\ {s+}(1-){n-s+}, $$

逐项拆解:Beta-Binomial 后验推导
  • \(p(\theta\mid\boldsymbol{x})\)：后验分布——看到数据 \(\boldsymbol{x}\) 之后，\(\theta\) 的分布
  • \(\propto\)：正比于——右边扔掉了一个不含 \(\theta\) 的常数（这里是分母 \(p(\boldsymbol{x})\)），只保留跟 \(\theta\) 有关的部分
  • \(\ell(\theta\mid\boldsymbol{x})\)：先验 × 似然——这是”后验正比于先验乘似然”这条核心公式的具体展开
  • \(\theta^s(1-\theta)^{n-s}\)：似然部分——\(n\) 次 Bernoulli 试验里 \(s\) 次成功、\(n-s\) 次失败的概率（二项分布概率质量函数去掉了组合数 \(\binom{n}{s}\)，因为它不含 \(\theta\)，本来就该被 \(\propto\) 吸收掉）
  • \(\dfrac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}\theta^{\alpha-1}(1-\theta)^{\beta-1}\)：先验部分——\(\text{Beta}(\alpha,\beta)\) 的概率密度函数，前面那一大截 Gamma 函数分式是归一化常数，同样不含 \(\theta\)
  • 第二行 \(\theta^{s+\alpha-1}(1-\theta)^{n-s+\beta-1}\)：把第一行两个”\(\theta\) 的幂”和两个”\((1-\theta)\) 的幂”分别合并——\(\theta^s \times \theta^{\alpha-1} = \theta^{s+\alpha-1}\)，\((1-\theta)^{n-s}\times(1-\theta)^{\beta-1}=(1-\theta)^{n-s+\beta-1}\)；同时把所有不含 \(\theta\) 的常数（包括 Gamma 函数那一串）全部并入 \(\propto\) 省略掉
  • 为什么能一眼看出这是 Beta 分布：\(\theta^{a-1}(1-\theta)^{b-1}\) 正是 Beta 分布密度函数的核心形式（对比你之前学的 \(f(x\mid\alpha,\beta)=\frac{1}{B(\alpha,\beta)}x^{\alpha-1}(1-x)^{\beta-1}\)）——所以只要把指数对上号，就能直接读出后验是 \(\text{Beta}(s+\alpha,\ n-s+\beta)\)，不需要真的去算那个复杂的归一化常数

而后验分布为 \(\text{Beta}(s+\alpha,\ n-s+\beta)\)。如果用二次损失函数来估计 \(\theta\)，则

\[ \hat\theta(\boldsymbol{x}) = E(\theta\mid\boldsymbol{x}) = \frac{s+\alpha}{n+\alpha+\beta} \]

常用的”无信息先验分布”为 \(\alpha=\beta=1\)，则 \(\text{Beta}(1,1)\) 为在 \([0,1]\) 区间上的均匀分布 \(U(0,1)\)，这时，

\[ \hat\theta(\boldsymbol{x}) = \frac{s+1}{n+2} \]

上面的模型形式上可以用下面的公式和图描述。

必须掌握（这些会直接出现在你的代码里）
  1. 共轭结构本身：\(\text{Beta}(\alpha,\beta)\) 先验 + Binomial 似然 → \(\text{Beta}(s+\alpha,\ n-s+\beta)\) 后验——这不是这本书随便举的一个例子，这就是单细胞甲基化数据建模的标准范式本身。你自己在最早那份框架文档里写的 \(k_{ij}\sim\text{Binomial}(n_{ij},\theta_{ij})\)，配 \(\theta_{ij}\sim\text{Beta}\) 先验，就是这条公式的原样应用。DSS、methylKit 这些真实的甲基化差异分析工具，内核都是这个（或它的经验贝叶斯变体）。

\[ k_{ij}\sim\text{Binomial}(n_{ij},\theta_{ij}) \] > 读作： k sub i j 服从，二项分布，参数是 n sub i j, \(\theta\) sub i j

  • \(k\) 观测到的甲基化 read 数（真正测到的数字，比如”5个甲基化read”）
  • \(n\) 该位点的总覆盖 read 数（总共测了几条read，比如”总共10条read”）
  • \(\theta\) 真实甲基化倾向（你想知道但看不见的那个概率，取值在0到1之间）
  • \(i\) 第几个细胞的编号（比如细胞1、细胞2……）
  • \(j\) 第几个位点的编号（比如基因组上第1个CpG位点、第2个……）
  • \(k_{ij}\) “细胞 i 在位点 j 处”测到的甲基化read数——两个下标锁定了具体是哪个细胞、哪个位点
  • \(n_{ij}\) “细胞 i 在位点 j 处”的总覆盖read数
  • \(\theta\) “细胞 i 在位点 j 处”的真实甲基化倾向
  • \(\alpha \beta\) Beta先验的两个超参数（前面学过，控制先验形状/强度）
  1. 后验均值公式 \(\hat\theta = \dfrac{s+\alpha}{n+\alpha+\beta}\)——这是你以后写代码时真正会敲进去的那一行。理解它的直觉比理解推导过程更重要：

\[ \hat\theta = \frac{s+\alpha}{n+\alpha+\beta} = \frac{\text{真实成功次数} + \text{先验"虚拟成功次数"}}{\text{真实总次数} + \text{先验"虚拟总次数"}} \]

\(\alpha,\beta\) 本质上是”先验帮你偷偷加的伪计数”——这个直觉在你处理低覆盖度位点（\(n_{ij}\) 很小）时特别关键：伪计数占比重，估计会被先验拉着走；覆盖度足够大时，伪计数占比可以忽略，估计几乎完全由数据决定。这正是你项目文档里提到的”经验贝叶斯收缩”的数学根源。

# hdrcde 需要联网从CRAN安装；这里手写一个等价的HDR计算函数，
# 不依赖额外包，原理相同：把密度曲线从高到低"切一刀"，
# 使刀线以上覆盖的面积恰好等于目标概率
compute_hdr_threshold <- function(dens_fun, prob, lower, upper, n_grid = 3000) {
  grid <- seq(lower, upper, length.out = n_grid)
  dens <- dens_fun(grid)
  ord <- order(dens, decreasing = TRUE)
  dx <- diff(grid)[1]
  cum_area <- cumsum(dens[ord] * dx)
  cutoff_idx <- which(cum_area >= prob)[1]
  dens[ord][cutoff_idx]
}

set.seed(1)
dens_fun <- function(theta) dbeta(theta, 2, 27)
x_grid <- seq(0, 0.5, length.out = 3000)
y <- dens_fun(x_grid)

t50 <- compute_hdr_threshold(dens_fun, 0.50, 0, 0.5)
t95 <- compute_hdr_threshold(dens_fun, 0.95, 0, 0.5)
t99 <- compute_hdr_threshold(dens_fun, 0.99, 0, 0.5)

plot(x_grid, y, type = "l", lwd = 2, col = "#1D3557",
     xlab = expression(theta), ylab = "density",
     main = "Beta(2,27) 的最高密度区域: 99% / 95% / 50%")

polygon(c(x_grid[y>=t99], rev(x_grid[y>=t99])), c(y[y>=t99], rep(0,sum(y>=t99))),
        col = adjustcolor("#B5432B", 0.2), border = NA)
polygon(c(x_grid[y>=t95], rev(x_grid[y>=t95])), c(y[y>=t95], rep(0,sum(y>=t95))),
        col = adjustcolor("#B5432B", 0.3), border = NA)
polygon(c(x_grid[y>=t50], rev(x_grid[y>=t50])), c(y[y>=t50], rep(0,sum(y>=t50))),
        col = adjustcolor("#B5432B", 0.5), border = NA)

legend("topright", legend = c("99% HDR", "95% HDR", "50% HDR"),
       fill = c(adjustcolor("#B5432B", 0.2),
                adjustcolor("#B5432B", 0.3),
                adjustcolor("#B5432B", 0.5)),
       bty = "n")

triplot 的两个参数分别是：

  • c(2,18)：先验超参数 \((\alpha,\beta)\)，即 \(\text{Beta}(2,18)\)
  • c(0,9)：观测数据 \((s,f)\)，即 \(s=0\) 次成功（感染）、\(f=9\) 次失败（无感染），共 \(n=9\) 次试验

3.2 Q1–Q4 拆解

  • Q1：\(\theta\) = 某个事件发生的真实概率
  • Q2：\(k \sim \text{Binomial}(n, \theta)\)
  • Q3：共轭先验 \(\theta \sim \text{Beta}(a, b)\)
  • Q4：闭式解 —— 后验仍是 Beta 分布

\[ \theta \mid k \;\sim\; \text{Beta}(a+k,\; b+n-k) \]

这是整本书里最干净的一个”闭式解”案例：先验、似然、后验全部停留在同一个分布族里，不需要 MCMC。

Code 
# LearnBayes 需要联网从CRAN安装；这里手写一个等价的triplot函数，
# 逻辑完全相同：同时画出先验、(标准化)似然、后验三条密度曲线
my_triplot <- function(prior, data, xmax = 0.5) {
  a <- prior[1]; b <- prior[2]   # 先验超参数(alpha, beta)
  s <- data[1];  f <- data[2]    # 观测: s次成功, f次失败

  theta <- seq(0.001, xmax, length.out = 500)

  prior_d <- dbeta(theta, a, b)
  # 似然本身不是概率密度(不积分为1),这里标准化一下方便跟先验/后验同尺度比较形状
  lik_raw <- theta^s * (1 - theta)^f
  lik_d <- lik_raw / sum(lik_raw) / diff(theta)[1]
  post_d <- dbeta(theta, a + s, b + f)

  ymax <- max(prior_d, lik_d, post_d)
  plot(theta, post_d, type = "l", lwd = 2, col = "#1D3557", ylim = c(0, ymax * 1.1),
       xlab = expression(theta), ylab = "密度",
       main = paste0("先验Beta(", a, ",", b, ") + 数据(s=", s, ",f=", f, ") → 后验"))
  lines(theta, prior_d, lwd = 2, col = "#6C757D", lty = 2)
  lines(theta, lik_d, lwd = 2, col = "#B5432B", lty = 3)
  legend("topright", legend = c("后验 posterior", "先验 prior", "似然 likelihood(标准化)"),
         col = c("#1D3557", "#6C757D", "#B5432B"), lwd = 2, lty = c(1, 2, 3), bty = "n")
}

my_triplot(c(2, 18), c(0, 9))

# 比例的推断：Bernoulli 试验

考虑只有"成功"和"失败"的独立试验，如果每次成功概率为 $\theta$，则称这些试验为有参数 $\theta$ 的 Bernoulli 试验，而试验结果是"成功"还是"失败"的分布为 $\text{Bernoulli}(\theta)$ 分布。如果在 $n$ 次 Bernoulli 试验中，有 $s$ 次成功（那么一定有 $f=n-s$ 次失败），则成功的次数称为服从有参数 $(n,\theta)$ 的二项分布。Bernoulli 分布是二项分布在 $n=1$ 时的特例。人们一般希望用试验中成功个数或者比例来对参数 $\theta$ 做推断。形式上，记观测值 $\boldsymbol{x}=(x_1,x_2,\ldots,x_n)$ 为参数 $\theta$ 的 Bernoulli 试验的结果，对应于"成功"或"失败"，每个 $x_i$ 取值为 1 或 0。

## 4.1 采用简单共轭先验分布

取 $\theta$ 的先验分布 $p(\theta)$ 为共轭先验分布 $\text{Beta}(\alpha,\beta)$，则 $s=x_1+x_2+\cdots+x_n$ 为一个充分统计量。后验分布

$$
p(\theta\mid \boldsymbol{x}) \propto \ell(\theta\mid\boldsymbol{x}) = \theta^s(1-\theta)^{n-s}\frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}\theta^{\alpha-1}(1-\theta)^{\beta-1}

\\
\propto \theta^{s+\alpha-1}(1-\theta)^{n-s+\beta-1}, \quad 0\leq\theta\leq 1
$$

::: {.callout-tip title="逐项拆解:Beta-Binomial 后验推导"}

- **$p(\theta\mid\boldsymbol{x})$**：后验分布——看到数据 $\boldsymbol{x}$ 之后，$\theta$ 的分布
- **$\propto$**：正比于——右边扔掉了一个不含 $\theta$ 的常数（这里是分母 $p(\boldsymbol{x})$），只保留跟 $\theta$ 有关的部分
- **$\ell(\theta\mid\boldsymbol{x})$**：先验 × 似然——这是"后验正比于先验乘似然"这条核心公式的具体展开
- **$\theta^s(1-\theta)^{n-s}$**：**似然部分**——$n$ 次 Bernoulli 试验里 $s$ 次成功、$n-s$ 次失败的概率（二项分布概率质量函数去掉了组合数 $\binom{n}{s}$，因为它不含 $\theta$，本来就该被 $\propto$ 吸收掉）
- **$\dfrac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}\theta^{\alpha-1}(1-\theta)^{\beta-1}$**：**先验部分**——$\text{Beta}(\alpha,\beta)$ 的概率密度函数，前面那一大截 Gamma 函数分式是归一化常数，同样不含 $\theta$
- **第二行 $\theta^{s+\alpha-1}(1-\theta)^{n-s+\beta-1}$**：把第一行两个"$\theta$ 的幂"和两个"$(1-\theta)$ 的幂"分别合并——$\theta^s \times \theta^{\alpha-1} = \theta^{s+\alpha-1}$，$(1-\theta)^{n-s}\times(1-\theta)^{\beta-1}=(1-\theta)^{n-s+\beta-1}$；同时把所有不含 $\theta$ 的常数（包括 Gamma 函数那一串）全部并入 $\propto$ 省略掉
- **为什么能一眼看出这是 Beta 分布**：$\theta^{a-1}(1-\theta)^{b-1}$ 正是 Beta 分布密度函数的核心形式（对比你之前学的 $f(x\mid\alpha,\beta)=\frac{1}{B(\alpha,\beta)}x^{\alpha-1}(1-x)^{\beta-1}$）——所以只要把指数对上号，就能直接读出后验是 $\text{Beta}(s+\alpha,\ n-s+\beta)$，不需要真的去算那个复杂的归一化常数

:::


而后验分布为 $\text{Beta}(s+\alpha,\ n-s+\beta)$。如果用二次损失函数来估计 $\theta$，则

$$
\hat\theta(\boldsymbol{x}) = E(\theta\mid\boldsymbol{x}) = \frac{s+\alpha}{n+\alpha+\beta}
$$

常用的"无信息先验分布"为 $\alpha=\beta=1$，则 $\text{Beta}(1,1)$ 为在 $[0,1]$ 区间上的均匀分布 $U(0,1)$，这时，

$$
\hat\theta(\boldsymbol{x}) = \frac{s+1}{n+2}
$$

::: {.callout-important title="必须掌握（这些会直接出现在你的代码里）"}

1. **共轭结构本身**：$\text{Beta}(\alpha,\beta)$ 先验 + Binomial 似然 → $\text{Beta}(s+\alpha,\ n-s+\beta)$ 后验——这不是这本书随便举的一个例子，**这就是单细胞甲基化数据建模的标准范式本身**。你自己在最早那份框架文档里写的 $k_{ij}\sim\text{Binomial}(n_{ij},\theta_{ij})$，配 $\theta_{ij}\sim\text{Beta}$ 先验，就是这条公式的原样应用。DSS、methylKit 这些真实的甲基化差异分析工具，内核都是这个（或它的经验贝叶斯变体）。

$$
k_{ij}\sim\text{Binomial}(n_{ij},\theta_{ij})
$$
> 读作： k sub i j **服从**，二项分布，参数是 n sub i j, $\theta$ sub i j

- $k$ 观测到的甲基化 read 数（真正测到的数字，比如"5个甲基化read"）
- $n$ 该位点的总覆盖 read 数（总共测了几条read，比如"总共10条read"）
- $\theta$ 真实甲基化倾向（你想知道但看不见的那个概率，取值在0到1之间）
- $i$ 第几个细胞的编号（比如细胞1、细胞2……）
- $j$ 第几个位点的编号（比如基因组上第1个CpG位点、第2个……）
- $k_{ij}$ "细胞 i 在位点 j 处"测到的甲基化read数——两个下标锁定了具体是哪个细胞、哪个位点 
- $n_{ij}$  "细胞 i 在位点 j 处"的总覆盖read数 
- $\theta$  "细胞 i 在位点 j 处"的真实甲基化倾向 
-  $\alpha \beta$ Beta先验的两个超参数（前面学过，控制先验形状/强度）

2. **后验均值公式** $\hat\theta = \dfrac{s+\alpha}{n+\alpha+\beta}$——这是你以后写代码时**真正会敲进去的那一行**。理解它的直觉比理解推导过程更重要：

$$
\hat\theta = \frac{s+\alpha}{n+\alpha+\beta} = \frac{\text{真实成功次数} + \text{先验"虚拟成功次数"}}{\text{真实总次数} + \text{先验"虚拟总次数"}}
$$

$\alpha,\beta$ 本质上是"先验帮你偷偷加的伪计数"——这个直觉在你处理**低覆盖度位点**（$n_{ij}$ 很小）时特别关键：伪计数占比重，估计会被先验拉着走；覆盖度足够大时，伪计数占比可以忽略，估计几乎完全由数据决定。这正是你项目文档里提到的"经验贝叶斯收缩"的数学根源。

:::

| 前缀 | 全称 | 回答的问题 | 输入 | 输出 |
|---|---|---|---|---|
| **d** | density | "这一点的概率密度是多少" | 一个 $\theta$ 值 | 密度高度 |
| **p** | probability | "小于等于这一点的累积概率是多少" | 一个 $\theta$ 值 | 一个概率（0~1） |

```{r}
#| label: fig-hdr-beta
#| fig-cap: "Beta(2,27) 的最高密度区域(HDR):99%/95%/50%三层嵌套区间"
#| fig-alt: "Beta(2,27)密度曲线,曲线下方用三层不同深浅的阴影标出99%、95%、50%最高密度区域,区域以密度峰值为中心向两侧扩展但不对称"

#| fig-height: 5

# hdrcde 需要联网从CRAN安装；这里手写一个等价的HDR计算函数，
# 不依赖额外包，原理相同：把密度曲线从高到低"切一刀"，
# 使刀线以上覆盖的面积恰好等于目标概率
compute_hdr_threshold <- function(dens_fun, prob, lower, upper, n_grid = 3000) {
  grid <- seq(lower, upper, length.out = n_grid)
  dens <- dens_fun(grid)
  ord <- order(dens, decreasing = TRUE)
  dx <- diff(grid)[1]
  cum_area <- cumsum(dens[ord] * dx)
  cutoff_idx <- which(cum_area >= prob)[1]
  dens[ord][cutoff_idx]
}

set.seed(1)
dens_fun <- function(theta) dbeta(theta, 2, 27)
x_grid <- seq(0, 0.5, length.out = 3000)
y <- dens_fun(x_grid)

t50 <- compute_hdr_threshold(dens_fun, 0.50, 0, 0.5)
t95 <- compute_hdr_threshold(dens_fun, 0.95, 0, 0.5)
t99 <- compute_hdr_threshold(dens_fun, 0.99, 0, 0.5)

plot(x_grid, y, type = "l", lwd = 2, col = "#1D3557",
     xlab = expression(theta), ylab = "density",
     main = "Beta(2,27) 的最高密度区域: 99% / 95% / 50%")

polygon(c(x_grid[y>=t99], rev(x_grid[y>=t99])), c(y[y>=t99], rep(0,sum(y>=t99))),
        col = adjustcolor("#B5432B", 0.2), border = NA)
polygon(c(x_grid[y>=t95], rev(x_grid[y>=t95])), c(y[y>=t95], rep(0,sum(y>=t95))),
        col = adjustcolor("#B5432B", 0.3), border = NA)
polygon(c(x_grid[y>=t50], rev(x_grid[y>=t50])), c(y[y>=t50], rep(0,sum(y>=t50))),
        col = adjustcolor("#B5432B", 0.5), border = NA)

legend("topright", legend = c("99% HDR", "95% HDR", "50% HDR"),
       fill = c(adjustcolor("#B5432B", 0.2),
                adjustcolor("#B5432B", 0.3),
                adjustcolor("#B5432B", 0.5)),
       bty = "n")
```

例 4.2：三合一图（triplot）

利用程序包 `LearnBayes` 的函数 `triplot`，可以基于 $\text{Beta}(2,18)$ 先验分布及数据（0次感染，9次无感染）画出先验密度、似然函数及后验密度图（见图4.1.3）：

```{r}
library(LearnBayes)
triplot(c(2,18), c(0,9), where="top")
```

`triplot` 的两个参数分别是：

- **`c(2,18)`**：先验超参数 $(\alpha,\beta)$，即 $\text{Beta}(2,18)$
- **`c(0,9)`**：观测数据 $(s,f)$，即 $s=0$ 次成功（感染）、$f=9$ 次失败（无感染），共 $n=9$ 次试验


## Q1--Q4 拆解

- **Q1**：$\theta$ = 某个事件发生的真实概率
- **Q2**：$k \sim \text{Binomial}(n, \theta)$
- **Q3**：共轭先验 $\theta \sim \text{Beta}(a, b)$
- **Q4**：闭式解 —— 后验仍是 Beta 分布

$$
\theta \mid k \;\sim\; \text{Beta}(a+k,\; b+n-k)
$$

这是整本书里最干净的一个"闭式解"案例：先验、似然、后验全部停留在同一个分布族里，不需要 MCMC。


```{r}
#| label: fig-triplot
#| fig-cap: "先验、似然、后验三合一图：Beta(2,18)先验 + 数据(s=0,f=9) → 后验Beta(2,27)"
#| fig-alt: "叠加线图,展示先验密度曲线Beta(2,18)、标准化似然曲线、后验密度曲线Beta(2,27)三者的相对位置,后验因数据全为失败而比先验更偏向theta接近0的一侧"
#| fig-width: 7
#| fig-height: 5

# LearnBayes 需要联网从CRAN安装；这里手写一个等价的triplot函数，
# 逻辑完全相同：同时画出先验、(标准化)似然、后验三条密度曲线
my_triplot <- function(prior, data, xmax = 0.5) {
  a <- prior[1]; b <- prior[2]   # 先验超参数(alpha, beta)
  s <- data[1];  f <- data[2]    # 观测: s次成功, f次失败

  theta <- seq(0.001, xmax, length.out = 500)

  prior_d <- dbeta(theta, a, b)
  # 似然本身不是概率密度(不积分为1),这里标准化一下方便跟先验/后验同尺度比较形状
  lik_raw <- theta^s * (1 - theta)^f
  lik_d <- lik_raw / sum(lik_raw) / diff(theta)[1]
  post_d <- dbeta(theta, a + s, b + f)

  ymax <- max(prior_d, lik_d, post_d)
  plot(theta, post_d, type = "l", lwd = 2, col = "#1D3557", ylim = c(0, ymax * 1.1),
       xlab = expression(theta), ylab = "密度",
       main = paste0("先验Beta(", a, ",", b, ") + 数据(s=", s, ",f=", f, ") → 后验"))
  lines(theta, prior_d, lwd = 2, col = "#6C757D", lty = 2)
  lines(theta, lik_d, lwd = 2, col = "#B5432B", lty = 3)
  legend("topright", legend = c("后验 posterior", "先验 prior", "似然 likelihood(标准化)"),
         col = c("#1D3557", "#6C757D", "#B5432B"), lwd = 2, lty = c(1, 2, 3), bty = "n")
}

my_triplot(c(2, 18), c(0, 9))
```
